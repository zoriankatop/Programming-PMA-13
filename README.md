
# Programming-PMA-13

## Опис проєкту
Репозиторій для лабораторних робіт з програмування
студентів групи ПМА-13 Львівського національного
університету імені Івана Франка.

## Мова програмування
C++

## Лабораторна робота
Табулювання функції на заданому відрізку.

Програма:
1. Зчитує крок h, введений користувачем.
2. Перевіряє правильність кроку.
3. Обчислює значення функції.
4. Виводить таблицю значень x та y.
5. Знаходить максимальне та мінімальне значення функції.

## Організація роботи
Кожен учасник створює власну гілку зі своїм ім'ям
та додає до неї свою лабораторну роботу.
